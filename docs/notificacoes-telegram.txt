# Notificações do Telegram

O workflow envia notificações internas pelo Telegram quando uma solicitação exige análise humana.

## 1. Cliente VIP

### Destinatário

Equipe financeira.

### Mensagem

Pedido de reembolso fora do prazo

Foi recebida uma solicitação de reembolso de um cliente que ultrapassou o prazo de 7 dias.

O sistema interrompeu o processamento automático, mas o cliente foi identificado como VIP. O caso deve ser avaliado pela equipe financeira para verificar a possibilidade de uma exceção.

Prazo informado ao cliente: retorno em até 24 horas.
